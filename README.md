# Machine-Learning-in-Python-Lab
Over the past few years, artificial intelligence has exploded in use. This has led Point Loma to add a machine learning class which teaches students the math that makes this technology possible. The math principles that make machine learning possible are complex and can be difficult to understand.

The team crafted a lab in which students can interact with real data using a guided Jupyter Notebook, which allows snippets of python code to be rewritten and run individually, enabling students to tweak and tinker to their hearts' content and gain a deeper understanding of the math behind AI.
